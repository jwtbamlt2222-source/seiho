Put-Call Parity（ヨーロピアンオプション）
\[C + Ke^{-rt} = P + S\]
\(C\)：コールオプション価格　\(P\)：プットオプション価格
\(K\)：行使価格（満期保証額）　\(r\)：無リスク金利　\(t\)：満期まで期間
\(S\)：原資産価格（特別勘定残高）
変額年金の最低保証 ＝ 投資信託（\(S\)）＋ プットオプション（\(P\)）
プロフィット・マージンの定義
\[\text{PM} = \frac{\displaystyle\sum_{t=1}^{n} \frac{\text{利益}_t}{(1+d)^t}}{\displaystyle\sum_{t=1}^{n} \frac{\pi_t \cdot l_{t-1}}{(1+d)^{t-1}}}\]
\(d\)：割引率　\(\pi_t\)：第\(t\)保険年度の保険料　\(l_{t-1}\)：第\(t\)保険年度始残存率
IRR（内部収益率）：分子をゼロにする割引率 \(d^*\) を求める
年平均改善率の合成式
\[(1-R_1)^5 \times (1-R_2)^{13} = (1-R)^{18}\]
\(R_1\)：1995〜2000年の5年間の幾何平均改善率
\(R_2\)：1980〜1993年の13年間の幾何平均改善率
\(R\)：18年間の年平均改善率（上記から算出）
将来死亡率：\(q^*_x = q^{(15)}_x \times (1-R_x)^{T_x}\)　（\(T_x\)：改善年数）
VaR と CTE の定義
\[\text{VaR}_\alpha(X) = \inf\{x \in \mathbb{R} : F_X(x) \geq 1 - \alpha\}\]
\[\text{CTE}_\alpha(X) = E\bigl[X \mid X \geq \text{VaR}_\alpha(X)\bigr]\]
\(\alpha\)：信頼水準（例：0.99）
VaR：損失が上位 \((1-\alpha)\times 100\)% に収まる最大値
CTE：VaRを超えた損失の条件付き期待値（テイルリスクを捕捉）
コヒーレントリスク尺度の4条件
劣加法性：\(\rho(X+Y) \leq \rho(X) + \rho(Y)\)
単調性：\(X \leq Y \Rightarrow \rho(X) \leq \rho(Y)\)
平行移動不変性：\(\rho(X + c) = \rho(X) + c\)
正同次性：\(\rho(\lambda X) = \lambda\,\rho(X) \quad (\lambda > 0)\)
CTE はこの4条件をすべて満たす。VaR は劣加法性を満たさない場合がある。
MVA（市場価格調整）算式
\[\text{解約返戻金} = \text{契約者価額} \times \left(\frac{1+i_1}{1+i_2+\alpha}\right)^{n - \frac{12t+\theta}{12}}\]
\(i_1\)：契約時の利率　\(i_2\)：解約時の利率　\(\alpha\)：タイムラグ対応マージン
\(n\)：保険期間（年）　\(t\)：経過年数　\(\theta\)：経過月数
金利上昇時（\(i_2\uparrow\)）→ 指数部の分数が1を下回る → 解約返戻金が減少
優良団体割引率の算式
\[\bar{\gamma}(1-\alpha) = \gamma + u(0.20)\sqrt{\frac{\gamma}{N}}\]
\[\therefore\quad \alpha = 1 - \frac{\gamma + u(0.20)\sqrt{\gamma/N}}{\bar{\gamma}}\]
\(\gamma\)：団体の実績死亡率　\(\bar{\gamma}\)：経験から割り出された死亡率
\(N\)：被保険者数　\(u(0.20) \approx 0.84\)（標準正規分布の片側20%点）
\(N\uparrow\) → \(\sqrt{\gamma/N}\downarrow\) → 右辺が小さくなる → \(\alpha\uparrow\)
通時一貫性の問題（2期間二項モデルの例）
時点0でCTE水準を積み立てても、悪いノード（\(d\)）に至ったとき
時点1での必要額が時点0の積立額を上回るケースが存在する：
\[\text{CTE}_{(d)} > \text{CTE}_{(0)}\] これにより「破綻確率5%未満の保証」と矛盾が生じる。
→ これを「通時一貫性の欠如」と呼ぶ（2020年問題）

③ 保険技術的公平性 vs 社会的公平性

2024・H25・H22頻出
500字程度の型
保険技術的公平性：各被保険者のリスクの大小に応じて保険料を設定し、リスクが高い者はより高い保険料を負担するという考え方。大数の法則に基づき同質リスク群団内で収支相等が成立することを目標とし、逆選択防止・収益安定化の観点から重要である。

社会的公平性：社会全体の観点から保険加入機会の平等・相互扶助の精神を重視する考え方。特定属性（遺伝情報・人種等）による差別的取扱いを排除することが求められる。

両者はトレードオフになる場合があり（例：がん罹患リスクを遺伝子情報で細分化すると保険技術的公平性は高まるが社会的公平性の観点から問題となりうる）、法令・監督指針の範囲内でバランスをとることが重要である。
大数の法則逆選択防止差別的取扱い禁止相互扶助トレードオフ

④ 解約リスクの2側面（解約益リスク・継続リスク）

H26・2022頻出
400字程度の型
解約益リスク（過去起因）：過去に支出した新契約費が回収できなくなるリスク。または低・無解約返戻金型において解約収入が得られなくなるリスク。解約率が予定を下回ると顕在化。

継続リスク（将来向き）：解約増加により将来の死差益等の収益が逸失するリスク。保険期間が長い商品ほど大きく、リスク濃縮が起こった場合は将来死差益が悪化。

【伝統的終身保険】：解約増→新契約費未回収分があれば収益悪化、回収済みなら解約控除分が収益増。
【低解約返戻金型終身保険】：払込期間中の解約率上昇→解約返戻金が少ないため保険会社は比較的有利だが、継続リスクの観点から将来利益が逸失する。
新契約費回収解約控除死差益リスク濃縮

⑤ 事後モニタリングと改善アクション

2022・2018・H27頻出
構成
目的：PDCAサイクルにより機動的に販売施策・価格を調整し、長期にわたる商品事業の健全性を維持すること。

収益性低下要因（例）：逆選択・モラルリスクの混入、感染症等の一時的発生率上昇、競争環境激化による件数減少、事業費の増加。

⑦ 標準責任準備金制度と営業保険料の関係

2020・H27頻出
600字程度の型
・標準基礎率（告示）と営業保険料の計算基礎率は各社の判断で独立。標準基礎率に合わせる必要はない。
・保険料基礎率が標準基礎率より有利な場合、保険期間途中で標準責任準備金の積立負担が発生する。
・一時払：予定利率>標準利率の場合、契約初期に大きな積立負担が生じうる。
・平準払（貯蓄性）：標準基礎率の純保険料が営業保険料を上回る場合、積立負担が大きくなる。
・積立負担は当該群団でセルフサポートすることが望ましく、恒常的な他群団からの立替えは好ましくない。
・収益の現在価値合計には影響しないが、タイミングのずれが経営上のリスクになる。
標準基礎率積立負担セルフサポートタイミングずれ

⑪ ヴァリデーション（モデル・ポイント精度検証）

H29・2022頻出
600字程度の型
ヴァリデーションとは、モデル・ポイントが保有契約群団をいかに良く代表しているかを評価する作業であり、会社全体の各種統計数値とモデル・ポイントを用いた算出値の差または比を確認することをいう。

主な確認項目：保有件数・保険金額・事業年度末保険料積立金（特に重要）・保険料等。項目が多いほど精度↑、ただし重要度に応じて選定。

留意点：①ある一時点で良い近似でも将来の各時点で必ずしも良い近似とは限らない。②死亡・解約等をシミュレートした動態的確認が有効。

⑫ 更新制度の保険会社・契約者のメリットと留意点

構成
保険会社のメリット：①更新時に料率改定が可能→将来の発生率上昇リスク吸収 ②責任準備金水準が低く抑えられる（短期性商品）。

更新型に適した商品：医療保険・定期保険等、将来の発生率変動が大きい商品。終身保険等の長期貯蓄性商品には馴染みにくい。
